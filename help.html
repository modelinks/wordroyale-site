遊び方・よくある質問

基本のルール

問題文を読んで、答えのカタカナを1文字目から順に盤面から取っていく早押しクイズです。みんな同じ盤面から取り合います。

  • 押せるのは答えの「次の文字」だけです。まちがった文字を押すと（答えにある文字でも、順番がちがえばまちがいです）、1.5秒間、解答がロックされます。
  • 相手に取られたタイルは、もう使えません。
  • 答えの後ろの文字ほど、タイルが少なくなります。
  • ptが入るのは、答えを完成させた人だけです。早く完成した順に、2人なら9pt、3〜4人なら9・6pt、5〜6人なら9・6・3pt、7〜8人なら9・6・3・1ptが入ります。
  • 先に30ptに届いた人の勝ちです。15問で誰も届かなければ、その時点のptで順位が決まります。
  • 分からないときは、何も押さずに待ちます。

くわしいルールは、アプリの設定 →「遊び方」で見られます。

モード

  • ランクマッチ：ランクの近い4人で対戦。1位・2位でXPアップ、3位はそのまま、4位でダウンします。人が集まらないときはCPUが入ります。
  • 練習モード：CPUと対戦。人数（2〜8人）・CPUの強さ・問題のレベルを選べて、先取ptなどのルールも変えられます。通信なしで遊べて、XPは変わりません。
  • 友達と対戦：部屋を作って、最大8人で遊べます。先取ptなどのルールはホストが変えられます。XPは変わりません。

よくある質問

友達と対戦するには？

ホームの「友達と対戦」で部屋を作り、6桁の部屋番号を友達に伝えてください（「番号を送る」で、LINEなどに送れます）。友達は「友達と対戦」の「部屋番号で参加」に番号を入れて参加します。フレンドになっていれば、部屋の「フレンドを招待」から直接招待することもできます。

フレンドになるには？

「フレンド」タブで自分のフレンドコード（8桁。はじめは「フレンドコードを発行」を押します）を相手に伝え（「送る」で、LINEなどに送れます）、相手に「フレンドを追加」から入れてもらいます。届いた申請を承認するとフレンドになります。友達と対戦の部屋では、いっしょにいる人の横のボタンから申請することもできます。フレンドは100人まで、招待は10分で切れます。

フレンドのアイコンの右下の点は、緑ならオンライン、グレーならオフラインです。

通知を止めたい・届きません

フレンド申請・フレンドになったこと・対戦の招待を、通知でお知らせします。設定の「通知」で、「フレンド申請」「対戦の招待」「運営からのお知らせ」を種類ごとにオン・オフできます。届かないときは、iPhoneの「設定」→「通知」→「ワードロワイヤル」で、通知が許可になっているかご確認ください。

ランクマッチの相手がCPUばかりです

同じランク帯に人がいないときは、隣のランク帯の人とも組みます。それでも集まらないときは、約10秒でCPUが入ります。遊ぶ人が増えると、人と当たりやすくなります。

音が鳴りません

マナーモード（消音）のときは、BGMと効果音は鳴りません。ほかのアプリで音楽を流しているときは、BGMだけ止まります。設定の「サウンド」で、BGM・効果音がオンになっているかもご確認ください。

問題や答えがまちがっています

試合の最後の結果の画面で、「問題ごと」の丸を押すと報告できます。お問い合わせから、問題文と答えを添えて送っていただいてもかまいません。

試合で出た問題と答えを見直したい

試合の最後の結果の画面の「問題と答えを見る」か、「戦績」タブの「最近の試合」から、その試合の問題と答えを見られます。

機種変更でデータを引き継げますか？

前の端末で、設定の「データ引き継ぎ」から Apple ID と連携しておくと、新しい端末で引き継げます。新しい端末では、最初の画面の「データ引き継ぎはこちら」か、設定の「データ引き継ぎ」→「引き継ぎを行う」から、同じ Apple ID でサインインしてください。引き継がれるのは、ランク・XP・ランクマッチの試合数・フレンド・ブロックリスト・名前とアバターです。練習モードの記録と、戦績（試合の履歴・正解率など）は端末に保存しているため引き継がれません。

連携していない場合も、iPhoneの「クイックスタート」や暗号化したバックアップで新しいiPhoneに移すと、引き継がれることがあります。

名前やアバターを変えたい

「アバター」タブで、いつでも変えられます。「スタイル」で全体の雰囲気をまとめて選んだり、「ランダム」でおまかせにしたりもできます。「こもの」の「わく」は、ランクマッチでそのランクに到達すると使えるようになります（錠前のついたわくを押すと、使えるようになる条件が出ます）。

不適切な名前のプレイヤーがいます

オンラインの試合の最後の結果の画面、友達と対戦の待合室、フレンドの画面で、相手の「…」から「名前を通報」か「ブロック」を選べます（CPUには「…」は出ません）。ブロックすると、フレンドから外れ、申請や招待が届かなくなり、ランクマッチでも同じ試合になりません。解除は、設定の「ブロックリスト」からできます。急ぎのときは、お問い合わせから、見かけた日時・モード・名前をお知らせください。

データやアカウントを消したい

設定の「アカウント削除」で、サーバーに保存しているランク・XP・ランクマッチの記録・フレンドを削除できます。サーバーのアカウントは、ランクマッチ・友達と対戦・フレンド・Apple ID 連携をはじめて使ったときに作られます（使う前は、サーバーにアカウントはありません）。端末の中のデータは、設定の「データの初期化」か、アプリの削除で消せます。どちらも元に戻せません。

料金はかかりますか？

無料で遊べます。広告もありません。
