プライバシーポリシー

制定：2026年11月6日 ／ 最終更新：2026年11月22日

ワードロワイヤル運営（以下「運営者」）は、iPhone アプリ「ワードロワイヤル」（以下「本アプリ」）で扱う情報を、次のとおり取り扱います。

1. 集めない情報

本アプリは、氏名・メールアドレス・電話番号・位置情報・連絡先・写真などの個人情報を集めません。

2. オンラインのアカウント

ランクマッチ・友達と対戦・フレンドを使うと、ゲームのサーバーに匿名のアカウントを作ります。アカウントは、ランダムに作った番号と、ゲームの中で表示する名前と、選んだアバターでできています。

3. サーバーに保存する情報

  • プレイヤーの番号、表示する名前、選んだアバター（用意した絵柄・色・フレームの組み合わせ）
  • XP とランク、ランクマッチの試合数と結果（順位・pt・XP の増減・日時）
  • 出題済みの問題の番号（同じ問題が続かないようにするため）
  • フレンドコード、フレンドと申請の一覧、友達対戦への招待（10分で消えます）
  • 最後にアプリを使った時刻（フレンドに「オンライン」かどうかを表示するため）
  • 通知を許可した場合: 端末に通知を届けるための番号（デバイストークン）と、受け取る通知の種類
  • Apple ID 連携をした場合: Apple から受け取るユーザーの番号（Apple ID ごとに決まる番号）と、連携を取り消すための値。名前やメールアドレスは受け取りません
  • 通報の記録（通報した人・された人の番号、そのときの名前、日時）

試合の進行のために送る操作（押したタイルなど）は、試合を進めるためだけに使い、試合が終わったら保存しません。また、ふつうのインターネット通信と同じく、IP アドレスなどの接続の情報がサーバーに届きます。

4. ほかのプレイヤーに表示される情報

対戦相手には、あなたの名前・アバター・ランクが表示されます。フレンドには、これに加えてオンラインかどうかが表示されます。名前には、本名や個人を特定できる内容を使わないでください。

5. 端末の中だけに保存する情報

練習の記録と戦績（試合の結果、遊んだ問題の履歴など）と設定は端末の中だけに保存し、外部には送りません。

6. 問題の報告

問題の誤りを報告する機能で扱うのは、問題の番号、選んだ理由、任意で書いたメモ、問題パックの版だけです。送信に対応した版では、これを運営者に送ります。メモには個人を特定できる内容を書かないでください。

7. 利用状況とクラッシュの情報

アプリをよくするため、Google LLC の Firebase（Analytics・Crashlytics）を使って、利用状況とクラッシュの情報を集めます。次の情報を Google に送ります。

  • 利用状況: 起動、チュートリアルの完了、試合の開始と終わり（モード・人数・順位・得点・途中でやめたか）、問題ごとの結果（問題の番号・最初に押すまでの時間など）、シェアしたこと、問題の報告（問題の番号と理由。書いたメモは送りません）
  • 端末の情報: 機種・iOS の版・アプリの版・言語・おおまかな地域（IP アドレスから）、アプリごとに作られる識別子（アプリを削除すると変わります）
  • クラッシュの情報: クラッシュしたときの機種・iOS の版・アプリの状態・処理の記録

名前・アバター・プレイヤーの番号・Apple ID など、アカウントの情報は送りません。目的は、遊ばれ方とクラッシュを知り、アプリを直すことです。

送った情報は Google のサーバー（日本国外にある場合があります）で保存・処理され、利用状況は最長14か月、クラッシュの情報は90日で消えます。アカウントとは結びついていないため、「アカウント削除」では消えません。通信できないときは、Firebase が端末に貯めて、あとでまとめて送ります。Google の扱いは Firebase のプライバシー情報で読めます。

8. 利用目的

集めた情報は、オンライン対戦・ランク・フレンドの機能を提供するため、不正の防止と障害の調査のため、本アプリをよくするためだけに使います。

9. 第三者への提供と外部のサービス

法令に基づく場合を除き、情報を第三者に提供・販売しません。サーバーには Cloudflare, Inc. のサービスを使っています。情報は Cloudflare のサーバー（日本国外にある場合があります）に保存・処理されます。

通知は Apple Inc. の通知サービス（Apple Push Notification service）を通じて送ります。そのため、デバイストークンと通知の文（フレンドの名前を含みます）を Apple に渡します。

通報があったときは、運営者が確かめるため、通報の内容（相手の番号と名前）を運営者が使う連絡用のサービスに送ります。

利用状況とクラッシュの情報の収集には、Google LLC の Firebase を使っています。送る情報は第7条のとおりです。

10. 広告とトラッキング

本アプリは広告を出しません。広告用の識別子（IDFA）は使わず、ほかの会社のアプリや Web サイトをまたいだトラッキングもしません。第7条の情報も、広告には使いません。

11. Apple から受け取る情報

iPhone の設定で「App デベロッパと共有」をオンにしている場合、Apple を通じて、クラッシュなどの診断情報を受け取ることがあります。この情報で、あなたを特定することはできません。

12. 情報の削除

本アプリの設定の「アカウント削除」で、サーバーに保存している情報をすべて削除できます（Apple ID 連携をしていれば、Apple 側の連携も取り消します）。端末の中の情報は、設定の「データの初期化」か、アプリの削除で消せます。第7条の情報は、アカウントとは結びついていないため、これらでは消えません。

13. このポリシーの変更

このポリシーを変えるときは、このページとアプリの更新でお知らせします。
