プライバシーポリシー

制定：2026年11月6日 ／ 最終更新：2026年11月28日

ワードロワイヤル運営（以下「運営者」）は、iPhone アプリ「ワードロワイヤル」（以下「本アプリ」）で扱う情報を、次のとおり取り扱います。

1. 集めない情報

本アプリは、氏名・メールアドレス・電話番号・連絡先・写真や、GPS などで測る端末の位置情報を集めません。位置情報の許可を求めることもありません。IP アドレスから割り出す国・地域ていどのおおまかな位置だけは、「7. 利用状況とクラッシュの情報」のとおり扱います。サポートサイトのお問い合わせフォームで送られたメールアドレスなどは、「15. お問い合わせ」のとおり扱います。

2. オンラインのアカウント

ランクマッチ・友達と対戦・フレンド・Apple ID 連携をはじめて使うときに、ゲームのサーバーに匿名のアカウントを作ります。アカウントは、ランダムに作った番号と、ゲームの中で表示する名前と、選んだアバターでできています。

3. サーバーに保存する情報

  • プレイヤーの番号、表示する名前、選んだアバター（用意した顔・髪型・服などのパーツと色・フレームの組み合わせ。写真は使いません）
  • XP とランク、ランクマッチの試合数と結果（順位・pt・XP の増減・日時）
  • 出題済みの問題の番号（同じ問題が続かないようにするため）
  • フレンドコード、フレンドと申請の一覧、対戦の招待（10分で切れます）
  • ブロックした相手の一覧
  • 最後にアプリを使った時刻（フレンドに「オンライン」かどうかを表示するため）
  • 通知を許可した場合: 端末に通知を届けるための番号（デバイストークン）と、受け取る通知の種類
  • Apple ID 連携をした場合: Apple から受け取るユーザーの番号（Apple ID ごとに決まる番号）と、連携を取り消すための値。名前やメールアドレスは受け取りません
  • 通報の記録（通報した人・された人の番号、そのときの名前、日時）と、通報によって戻した名前の記録
  • 利用規約に反したためにオンラインの機能を止めた場合: 止めた日時と、その理由のメモ

試合の進行のために送る操作（押したタイルなど）は、試合を進めるためだけに使い、試合が終わったら保存しません。また、ふつうのインターネット通信と同じく、IP アドレスなどの接続の情報がサーバーに届きます。IP アドレスは、短い時間に大量に送るなどの不正な使い方を防ぐ（回数を制限する）ために使い、ゲームのデータベースには保存しません。

4. ほかのプレイヤーに表示される情報

対戦相手には、あなたの名前・アバター・ランクが表示されます。フレンドには、これに加えてオンラインかどうかが表示されます。名前には、本名や個人を特定できる内容を使わないでください。

5. 端末の中だけに保存する情報

練習の記録と戦績（試合の結果、遊んだ問題の履歴など）と設定は端末の中だけに保存し、外部には送りません。

6. 問題の報告と、新しい問題の取得

問題の誤りを報告する機能で送るのは、問題の番号、選んだ理由、任意で書いたメモ、問題パックの版、報告した日時だけです。これをゲームのサーバーに送り、問題を直すために使います。アカウントや IP アドレスとは結びつけずに保存します。通信できないときは端末の中に貯めておき、あとで送ります。メモには個人を特定できる内容を書かないでください。

新しい問題・直した問題は、配信用のサーバー（Cloudflare）から問題のファイルをダウンロードして取り込みます。このとき、あなたの情報は送りません（ふつうのインターネット通信と同じく、IP アドレスなどの接続の情報は届きます）。

7. 利用状況とクラッシュの情報

アプリをよくするため、Google LLC の Firebase（Analytics・Crashlytics）を使って、利用状況とクラッシュの情報を集めます。次の情報を Google に送ります。

  • 利用状況: 起動、チュートリアルの完了、試合の開始と終わり（モード・人数・順位・得点・途中でやめたか）、問題ごとの結果（問題の番号・最初に押すまでの時間など）、シェアしたこと、問題の報告（問題の番号と理由。書いたメモは送りません）
  • 画面と操作の流れ: 開いた画面、チュートリアルと最初の設定（名前・アバター・規約の同意）の進み方、ランクマッチの待ち時間とマッチングの結果、友達と対戦の部屋・フレンド・結果の画面での操作（部屋を作った・申請した・招待した・通報したなど。相手がだれかは送りません）、アバターを保存したときに選んだパーツの種類（髪型・服・ぼうし・めがね・わく）、設定の変更（サウンド・通知などのオン・オフ）、通知の許可、Apple ID 連携・アカウント削除・データの初期化をしたこと、試合中の通信の切断と再接続、評価のお願いを出したこと
  • 端末の情報: 機種・iOS の版・アプリの版・言語・おおまかな地域（IP アドレスから割り出す国・地域）、アプリごとに作られる識別子（アプリを削除すると変わります）
  • クラッシュの情報: クラッシュしたときの機種・iOS の版・アプリと端末の状態（メモリーや保存の空き容量など）・処理の記録

名前・プレイヤーの番号・Apple ID・フレンドコード・部屋番号など、あなたやほかのプレイヤーを見分けられる情報は送りません。アバターについて送るのは、保存したときに選んだパーツの種類だけです。広告用の識別子（IDFA）を扱う部品も、本アプリには入れていません。目的は、遊ばれ方・つまずきやすい所・クラッシュを知り、アプリを直すことです。

送った情報は Google のサーバー（日本国外にある場合があります）で保存・処理されます。アカウントとは結びついていないため、「アカウント削除」では消えません。通信できないときは、Firebase が端末に貯めて、あとでまとめて送ります。Google の扱いは Firebase のプライバシー情報で読めます。

8. 利用目的

集めた情報は、オンライン対戦・ランク・フレンドの機能を提供するため、不正の防止と障害の調査のため、本アプリをよくするためだけに使います。

9. 第三者への提供と外部の事業者

法令に基づく場合を除き、情報を第三者に提供・販売しません。本アプリを動かすために次の事業者のサービスを使い、それぞれに必要な情報だけを渡します。どれも米国の会社で、情報は日本国外のサーバーで保存・処理されることがあります。

  • Cloudflare, Inc.（ゲームのサーバーとデータベース・問題の配信）: 3. の情報と接続の情報を保存・処理します。お問い合わせフォームの内容（15.）は、保存せずに運営者のチャンネル（Discord）へ中継します。Cloudflare のプライバシーポリシー
  • Google LLC（Firebase）: 7. の利用状況とクラッシュの情報を集めます。Firebase のプライバシー情報
  • Apple Inc.（通知・Apple ID 連携）: 通知は Apple の通知サービス（Apple Push Notification service）を通じて送るため、デバイストークンと通知の文（フレンドの名前を含みます）を Apple に渡します。Apple ID 連携では、連携の確認と取り消しのために Apple のサーバーとやりとりします。Apple のプライバシーポリシー
  • Discord Inc.（運営者への知らせ）: 通報があったときは、運営者が確かめるため、通報した人・された人の番号と、通報された名前を、運営者のチャンネルに送ります。お問い合わせフォームで送られた内容（目的・メールアドレス・お問い合わせ内容）も、運営者のチャンネルに送ります。Discord のプライバシーポリシー

運営者は、これらの事業者が、それぞれの利用規約とデータの取り扱いの条件に従い、このポリシーと同等以上の水準で情報を守ることを確かめたうえで使っています。

10. 広告とトラッキング

本アプリは広告を出しません。広告用の識別子（IDFA）は使わず、ほかの会社のアプリや Web サイトをまたいだトラッキングもしません。7. の情報も、広告には使いません。

11. Apple から受け取る情報

iPhone の設定で「App デベロッパと共有」をオンにしている場合、Apple を通じて、クラッシュなどの診断情報を受け取ることがあります。この情報で、あなたを特定することはできません。

12. 保存する期間

  • サーバーのアカウントの情報（3.）: アカウントを削除するまで保存します。ただし、対戦の招待は10分で切れ、切れた招待は、招待された人が一覧を読むときに消えます。フレンドから外したりブロックしたりすると、その相手とのフレンド・申請・招待の情報は消えます。
  • 通報の記録: 通報した人か通報された人がアカウントを削除するまで保存します。運営者のチャンネルに送った通報の知らせは、対応の記録として運営者が保管し、要らなくなったら消します。
  • 問題の報告（6.）: 問題を直すのに必要な間、保存します。
  • お問い合わせ（15.）: 運営者のチャンネルに届いた内容と、メールのやりとりは、対応の記録として運営者が保管し、要らなくなったら消します。
  • サーバーのログ（接続の記録など）: 7日以内に消えます。
  • 利用状況とクラッシュの情報（7.）: 利用状況は最長14か月、クラッシュの情報は90日で消えます。
  • バックアップ: 障害に備えて、データベースを前の時点に戻すための記録が最長30日残ります。削除した情報も、その間はここに残ることがありますが、障害から元に戻すとき以外には使いません。運営者が作業の前に作る控えも、要らなくなったら消します。

13. 情報の削除と、送信の停止

  • 本アプリの設定の「アカウント削除」で、サーバーに保存している情報をすべて削除できます（Apple ID 連携をしていれば、Apple 側の連携も取り消します）。
  • 端末の中の情報は、設定の「データの初期化」か、アプリの削除で消せます。
  • Apple ID 連携は、設定の「データ引き継ぎ」の「連携を解除」でやめられます。通知は、iPhone の「設定」→「通知」でいつでも止められます。
  • 7. の情報は、アカウントとは結びついていないため、「アカウント削除」や「データの初期化」では消えません。アプリを削除すると識別子が変わり、それまでの情報とは結びつかなくなります。
  • そのほかの削除のご依頼や、情報の取り扱いについてのご相談は、お問い合わせフォームからお知らせください（15.）。

14. このポリシーの変更

このポリシーを変えるときは、このページとアプリの更新でお知らせします。

15. お問い合わせ

ワードロワイヤル運営
お問い合わせフォーム

お問い合わせフォームでは、お問い合わせの目的・メールアドレス・お問い合わせ内容を受け取ります。これらは、ゲームのサーバー（Cloudflare）を通して運営者のチャンネル（Discord）に届け、お問い合わせへの回答と対応のためだけに使います。回答は、入力されたメールアドレスにメールでお送りします。ゲームのデータベースには保存しません。送るときの IP アドレスは、短い時間に大量に送るなどの不正な使い方を防ぐ（回数を制限する）ためだけに使います。
